# 使用示例

## 素材分析

```text
用 $haofeifan-tech-video-studio 只读分析这些口播、屏幕录制和参考视频。输出媒体清单、重复 take、音频风险、可量化风格指纹、B-roll 缺口、封面方向和未知项。先不要改时间线或调用付费生成。
```

## 端到端制作

```text
用 $haofeifan-tech-video-studio 把素材剪成 9:16 的科技口播。先按实际转录删除口误、重录和无效停顿，再做短语字幕、内容相关 B-roll、轻科技 HUD、内容匹配的无人声 BGM 和片中真人封面。保留基础版和包装版，交付可编辑工程；暂不发布。
```

## 模仿参考风格

```text
分析参考视频的 hook 秒数、平均镜头长度、字幕位置、动效进入退出、颜色和每 10 秒视觉事件密度。只迁移这些可观察规律，不复制文案、标识、水印或人物身份，然后把风格应用到我的口播素材。
```

## 补充相关素材

```text
读取已经锁定的最终时间线和字幕。为需要证据、解释或节奏变化的段落建立语义覆盖表，优先使用我提供的素材；只为剩余缺口生成相关图片或短视频。每个素材都要记录对应原句、时间、来源、事实状态和画面作用，并检查淡入、中点、淡出。
```

## BGM 与封面

```text
根据成片内容选择或生成低存在感的无人声 BGM，锁片后连续铺满节目，设置人声优先的 ducking 和首尾淡化。封面必须使用视频内真人，标题提炼核心结果或冲突，并检查 1080x1920 原图和 270x480 手机缩略图。
```

## 建议输入

素材之外，提供以下信息会提高稳定性：

- 目标平台和比例；
- 是否有参考视频；
- 是否允许生成图片、视频或音乐；
- 期望的科技感等级；
- 是否需要封面、字幕文件和最终导出；
- 必须保留或禁止出现的内容。

可以用 [制作 Brief 模板](edit-brief-template.md) 记录这些信息。
