# 升级指南

本仓库是公开版本的唯一来源。个人安装目录只作为运行副本；修改完成并验证后，从仓库安装到 Codex，避免仓库与本地 Skill 长期分叉。

## 版本规则

- `PATCH`：措辞修正、兼容性修复、脚本 bug 修复，不改变默认制作行为。
- `MINOR`：新增可选工作模式、工具适配、质量检查或向后兼容的输出字段。
- `MAJOR`：改变默认剪辑顺序、授权边界、交付契约、目录结构或依赖方式。

每次发布同步更新 `VERSION` 和 `CHANGELOG.md`。Git tag 使用 `vX.Y.Z`。

## 不可破坏的核心不变量

1. 有原始音频时，以实际转录和最终时间线为时间真相。
2. 新视觉版本保留基础时间线，不覆盖用户原素材。
3. B-roll 和生成素材必须映射到实际口播，记录来源与事实状态。
4. 真人脸、嘴、手势、字幕和关键 UI 是受保护区域。
5. BGM 在锁片后铺设，人声始终优先；未测量时不声称达到响度目标。
6. 付费生成、发布和不可逆操作只在用户授权范围内执行。
7. “完成”必须有时间线回读、关键帧检查或媒体文件验证作为证据。

## 升级步骤

1. 用真实失败案例描述触发条件、当前行为和期望行为。
2. 判断修改属于核心原则、阶段流程、工具集成、脚本还是质量门槛。
3. 把供应商专属参数限制在 `references/integrations.md` 或独立适配文档中。
4. 修改最小范围，并补充能验证行为的测试或检查步骤。
5. 运行仓库校验、单元测试和 Codex Skill 校验。
6. 对视觉或时间线改动查看真实输出，不以脚本成功退出代替视觉检查。
7. 更新版本、变更记录和迁移说明后再发布。

## 编辑器适配契约

新编辑器至少应提供以下能力中的相关子集：

- 列出媒体及其时长、尺寸、帧率和音频状态；
- 获得带时间码的转录；
- 创建或复制时间线；
- 添加、更新、删除和回读轨道 item；
- 管理字幕并检查溢出；
- 输出指定时间点的组合帧；
- 设置音频淡化、增益和 ducking，或提供等价混音方式；
- 导出后返回可验证的本地文件。

适配层只翻译这些能力，不改变内容决策和质量门槛。

## 近期升级方向

- 风格指纹模板：把参考片节奏、字幕、构图、颜色和密度输出为结构化 JSON。
- 语义覆盖检查：检测口播段落、B-roll 映射、事实状态和素材落地是否完整。
- 封面候选评分：根据清晰度、睁眼、表情、负空间和缩略图可读性排序。
- 音频报告：统一记录 LUFS、true peak、ducking、淡化和未验证项。
- 编辑器适配层：在不修改核心 Skill 的情况下接入更多可编辑 NLE。

这些方向是维护计划，不代表当前版本已经实现。发布说明必须区分已完成能力与计划。
