# 科技口播完整制作流程

这条流程统一参考风格拆解、口播剪辑、内容补画、科技包装、音频、封面和交付。根据用户要求从必要阶段开始，不重复已完成且已验证的工作。

## 0. 范围与版本

- 确认目标平台、画幅、交付物、是否有参考、是否需要封面、B-roll、音乐和生成素材。
- 用户只要分析时保持只读。用户明确要求直接制作时可继续执行普通可逆编辑；付费生成、发布和覆盖原文件仍按其实际授权处理。
- 已有获批时间线需要另一种风格时，先复制时间线并命名版本，例如“基础剪辑”“科技包装版”“精简版”。不在同一时间线上破坏性试验。
- 新版本继承已经锁定的 A-roll、字幕和素材映射，除非用户明确要求重新剪内容。

## 1. 素材与参考盘点

输出实际媒体表：文件、角色、时长、比例、帧率、音频、转录状态、重复 take、真实截图/B-roll、参考和未知项。有原音频时以实际转录为时间真相，成稿用于结构与术语校正。

参考视频转换为可执行风格指纹：

| 维度 | 必须记录 |
|---|---|
| 节奏 | hook 秒数、平均镜头时长、加速点、安静段 |
| 构图 | 人物位置、头顶、负空间、截图裁切、安全区 |
| 字幕 | 位置、行数、字号、描边、关键词规则 |
| 动效 | 进入/退出、缩放幅度、缓动、同时事件上限 |
| 声音 | 人声优先级、音乐作用、SFX 密度、淡化 |
| 颜色 | 背景、正文、主强调色、警示色及使用条件 |
| 密度 | 每 10 秒视觉事件数量和故意留白的位置 |
| 封面 | 主体、标题层级、安全区和缩略图表现 |

只迁移可观察的节奏、层级、材质和动画语法，不复制参考的文案、人物身份、标识、水印或私有提示词。

## 2. A-roll 结构锁定

1. 转录全部候选，识别重复 take、错误、口癖、停顿和无效尾巴。
2. 按表达完整度、口齿、信噪比、响度稳定、画面稳定和时长选择完整 take。
3. 以完整语义和音素边界删改，保留自然呼吸，不拼接未完成半句。
4. 复杂重排先给内容级决策表；用户已授权端到端制作时按已确认方向执行。
5. 锁定后处理语音切点交叉淡化并读回实际时间线。后续包装都以这条最终时间线为基准。

## 3. 字幕

- 从最终时间线生成，不沿用剪辑前时间。
- 中文按短语分段，通常不超过两行；人名、品牌和术语不拆分。
- 选择一个全片字幕系统。关键词强调只选择有理解、记忆、行动或结论价值的最短真实词组。
- 逐帧检查字幕、人脸、嘴、手势和关键 UI；已有烧录字幕不再叠加。

## 4. 内容补画

按 [content-driven-broll.md](content-driven-broll.md) 建立语义覆盖表。用户素材和真实证据优先，生成素材只补缺口。每个素材记录对应原句、时间、来源、事实状态、画面作用和验证结果。

## 5. 科技感包装导演

先为每个语义 beat 记录：`spokenIdea`、`visualMode`、`overlayType`、`motion`、`protectionNotes` 和可选声音事件。视觉模式只能选一个主体：

- `human-only`：人物和表达本身足够；
- `supporting-media`：图片/视频承担解释；
- `mixed-minimal`：人物保留，只在真实负空间加入轻量 MG；
- `fullscreen-information`：章节、关系或结论需要全屏信息场景。

使用一套有限且可重复的组件词汇：

- 开场 hook card：0–3 秒内给出一个冲突或承诺；
- 章节标识：0.5–1.2 秒完成识别，随后让位给内容；
- 关键词强调：短词、短线或轻量数据信号；
- 截图 callout：只指向当前讲到的区域；
- 全屏解释：只用于高信息密度关系、流程或结论；
- 结束收束：回到核心观点，不自行添加关注、完成贴纸或倒计时。

先确定静态终态和安全位置，再做进入、停留和退出。覆盖层默认透明；只有明确的全屏信息 beat 使用不透明背景。每一时刻最多一个主运动事件和一个辅助事件。

## 6. 音频

- A-roll 结构锁定前不铺最终 BGM。
- 多条 take 先统一人声基准，再调音乐和 SFX。默认节目综合约 `-14 LUFS ±1`，true peak 不高于 `-1 dBTP`；未测量时明确标记。
- 从最终转录、内容情绪和段落结构提取音乐方向；口播默认选无人声、低旋律占用、无强烈 drop 的音乐床，不能只因为“科技感”就加入刺耳高频、代码音或预告片重击。
- BGM 连续覆盖最终节目时长，不能跟随删词点硬切；长于节目时裁到真实结尾，短于节目时交叠循环，不拉伸超出源时长。首尾通常做 1–2 秒淡化。
- 编辑器支持时，将真人口播/旁白轨设为 `anchor`、BGM 轨设为 `follower`，读回实际 ducking 配置。优先使用自动初始化的压低量；没有试听或测量依据时，不同时叠加大幅片段降益和很深的手动 duck。
- SFX 只服务开场、章节或有意义的交互，不为每个动画配声音。

## 7. 封面

- 口播作品以片中真人为默认主焦点，从原视频挑选睁眼、表情自然、清晰且有排版空间的一帧；不改变身份或用陌生生成脸替代。
- 一个主焦点，一个结果或冲突，主标题通常 3–8 个汉字，副标题补足主题；文案必须来自视频真实核心观点。
- 画面、字体和强调色与视频共享视觉语言，但封面单独做移动端缩略图检查。
- 文字避开眼睛、鼻子和嘴，优先使用负空间或肩部以下；默认同时检查 1080×1920 原图和约 270×480 的手机缩略图。
- 提供 outcome-led、topic-led 或 before/after 等不同信息策略时，每个候选都必须对应视频真实内容。

## 8. 验收与交付

ChatCut 或其它可编辑时间线：

1. 读回轨道、item、字幕、效果和素材区间。
2. 开场、章节、最密集包装段、B-roll 和结尾都检查组合帧。
3. 每个素材检查淡入、中点、淡出；MG 同时检查动画中间态和稳定态。
4. 确认无黑帧、意外重叠、字幕遮挡、裁字、半个音素、错误事实和突然的声音变化。

渲染文件：完整解码并用媒体工具确认尺寸、时长、帧率、音频、响度和峰值。用户未要求导出时交付可编辑复看片，清楚说明未完成的 BGM、封面、媒体测量或事实核验。
